# Настройки Яндекс Облака (вкладка "Яндекс Облако")

## Обзор

Вкладка **"Яндекс Облако"** заменила устаревшую вкладку "Настройки API" и предоставляет современный способ аутентификации через JSON-ключ сервисного аккаунта с автоматическим получением IAM-токенов.

## Отличия от старой системы

| Параметр | Старая система (API-ключ) | Новая система (Яндекс Облако) |
|----------|---------------------------|-------------------------------|
| **Аутентификация** | API-ключ в заголовке `Api-Key` | JSON-ключ → IAM-токен → Bearer токен |
| **Безопасность** | Статический ключ, долгое хранение | Временные токены (3 часа) |
| **Настройка** | Простая, но менее безопасная | Требует создания сервисного аккаунта |
| **Object Storage** | Не поддерживался | Полная поддержка S3-совместимого хранилища |
| **Срок действия** | Бессрочный | IAM-токен действителен 3 часа |

## Поля настройки

### Обязательные поля

#### 1. Приватный ключ (JSON-ключ сервисного аккаунта)

**Что это:** Полный JSON-файл сервисного аккаунта Яндекс Облака.

**Формат:**
```json
{
  "id": "...",
  "service_account_id": "...",
  "created_at": "...",
  "private_key": "-----BEGIN PRIVATE KEY-----\n...\n-----END PRIVATE KEY-----\n",
  "key_algorithm": "RSA_2048"
}
```

**Где получить:**
1. Перейдите на [console.cloud.yandex.ru](https://console.cloud.yandex.ru/)
2. Выберите каталог → Сервисные аккаунты
3. Создайте сервисный аккаунт с ролью `editor` или `ai.languageModels.user`
4. Создайте новый ключ → Скачать JSON
5. Откройте файл и скопируйте содержимое в поле

**Как использовать:**
- Скопируйте **полное содержимое** JSON-файла
- Вставьте в текстовое поле "Приватный ключ (JSON-ключ сервисного аккаунта)"
- Система автоматически проверит валидность JSON

#### 2. Folder ID

**Что это:** Идентификатор каталога в Яндекс Облаке, где будут использоваться сервисы.

**Формат:** `b1g...` (начинается с `b1g`)

**Где получить:**
1. Перейдите на [console.cloud.yandex.ru](https://console.cloud.yandex.ru/)
2. В верхней части страницы выберите каталог
3. Скопируйте ID каталога (начинается с `b1g`)

**Для чего используется:**
- SpeechKit (распознавание речи)
- Другие сервисы Яндекс Облака

### Опциональные поля (Object Storage)

Эти поля нужны для работы с большими файлами через Object Storage.

#### 3. Имя бакета

**Что это:** Имя бакета в Object Storage для загрузки файлов.

**Пример:** `my-audio-bucket`

#### 4. Access Key ID

**Что это:** Публичный ключ доступа к Object Storage.

**Формат:** `YC...` (начинается с `YC`)

**Где получить:**
1. Перейдите в раздел "Object Storage" в консоли
2. Создайте ключ доступа
3. Скопируйте Access Key

#### 5. Secret Access Key

**Что это:** Секретный ключ доступа к Object Storage.

**Важно:** Храните в секрете, не передавайте третьим лицам.

## Как настроить пошагово

### Шаг 1: Создание сервисного аккаунта

```
1. console.cloud.yandex.ru → Каталог → Сервисные аккаунты
2. "Создать сервисный аккаунт"
3. Имя: audio-analyzer-sa
4. Описание: Для распознавания аудио
5. Роль: editor (или ai.languageModels.user)
6. Нажмите "Создать"
```

### Шаг 2: Создание JSON-ключа

```
1. Выберите созданный сервисный аккаунт
2. Перейдите на вкладку "Ключи"
3. "Создать новый ключ"
4. Тип ключа: JSON
5. Скачайте файл (например, sa-key.json)
```

### Шаг 3: Получение Folder ID

```
1. console.cloud.yandex.ru
2. Вверху страницы выберите нужный каталог
3. Скопируйте ID (вида b1gxxxxxxxxxxxxxxx)
```

### Шаг 4: Настройка в приложении

```
1. Откройте приложение
2. Перейдите на вкладку "Яндекс Облако"
3. Вставьте содержимое sa-key.json в поле "Приватный ключ"
4. Укажите Folder ID
5. Настройки автоматически сохранятся
```

### Шаг 5: (Опционально) Настройка Object Storage

```
1. console.cloud.yandex.ru → Object Storage
2. "Создать бакет"
3. Имя: my-audio-bucket
4. Создайте ключ доступа (Access Key + Secret Key)
5. Скопируйте ключи в соответствующие поля
```

## Как это работает

### Процесс аутентификации

```
┌─────────────────┐
│ JSON-ключ       │
│ (сервисный      │
│ аккаунт)        │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ IAM Token       │
│ (запрос к       │
│ token.api.      │
│ cloud.yandex.ru)│
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ Bearer токен    │
│ (используется   │
│ в заголовке     │
│ Authorization)  │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ SpeechKit API   │
│ (распознавание) │
└─────────────────┘
```

### Пример запроса (рабочая схема)

Файл предварительно загружается в Object Storage, затем отправляется асинхронный запрос:
```http
POST https://transcribe.api.cloud.yandex.net/speech/stt/v2/longRunningRecognize
Authorization: Api-Key YOUR_API_KEY
Content-Type: application/json

{
  "folderId": "b1gbre1u8o8khnnig1fn",
  "config": {
    "specification": {
      "languageCode": "ru-RU",
      "model": "general",
      "profanityFilter": false,
      "audioEncoding": "MP3",
      "sampleRateHertz": 48000,
      "audioChannelCount": 1,
      "rawResults": false
    }
  },
  "audio": { "uri": "https://storage.yandexcloud.net/speech-file/audio-uploads/file.mp3" }
}
```
Затем операция опрашивается: `GET https://operation.api.cloud.yandex.net/operations/{id}` до `done=true`,
текст собирается из `response.chunks[].alternatives[0].text`.

## Преимущества новой системы

✅ **Безопасность**: Временные токены вместо статических ключей  
✅ **Гибкость**: Поддержка Object Storage для больших файлов  
✅ **Масштабируемость**: Легко добавлять новые сервисы Яндекс Облака  
✅ **Соответствие best practices**: Рекомендованный Яндексом способ  
✅ **Автоматическое обновление**: IAM-токены обновляются автоматически  

## Индикаторы статуса

На вкладке "Яндекс Облако" отображается статус настройки:

- ✅ **JSON-ключ: Настроен** — ключ загружен и распознан
- ❌ **JSON-ключ: Не указан** — нужно ввести ключ
- ✅ **Folder ID: b1g...** — каталог указан
- ❌ **Folder ID: Не указан** — нужно указать каталог
- ✅ **Object Storage: my-bucket** — бакет настроен
- ⚪ **Object Storage: Не настроен** — опционально
- ✅ **Ключи S3: Настроены** — доступ к хранилищу готов
- ⚪ **Ключи S3: Не указаны** — опционально

## Проверка работы

### 1. Проверка в localStorage

Откройте консоль браузера (F12) → Application → Local Storage:

```json
{
  "serviceAccountKey": "{\"id\":\"...\",\"service_account_id\":\"...\"}",
  "folderId": "b1g...",
  "bucketName": "my-bucket",
  "accessKeyId": "YC...",
  "secretAccessKey": "..."
}
```

### 2. Проверка бэкенда

Бэкенд использует новые настройки через модель `YandexCloudSettings`:

```bash
curl http://localhost:5000/api/yandex-cloud/settings
```

Ответ:
```json
{
  "folder_id": "b1g...",
  "bucket_name": "my-bucket",
  "has_service_account_key": true,
  "iam_token_valid": true
}
```

## Миграция со старой системы

Если вы использовали старую вкладку "Настройки API":

1. **Не удаляйте старые настройки сразу** — они могут понадобиться для обратной совместимости
2. **Настройте новую систему** через вкладку "Яндекс Облако"
3. **Протестируйте распознавание** с новыми настройками
4. **Обновите документацию** и инструкции для пользователей
5. **Пометьте старую вкладку как устаревшую** (deprecated)

## Решение проблем

### Проблема: "Неверный формат JSON"

**Решение:**
- Убедитесь что скопировали **полное** содержимое JSON-файла
- Проверьте что ключ начинается с `{` и заканчивается `}`
- Убедитесь что поле `private_key` содержит корректный PEM-ключ

### Проблема: "IAM-токен недействителен"

**Решение:**
- IAM-токены действительны только 3 часа
- Бэкенд должен автоматически обновлять токены
- Проверьте что у сервисного аккаунта есть нужные роли

### Проблема: "Нет доступа к SpeechKit"

**Решение:**
- Проверьте роль сервисного аккаунта (`ai.languageModels.user` или `editor`)
- Убедитесь что указан правильный Folder ID
- Проверьте квоты в консоли Яндекс Облака

## Безопасность

⚠️ **Важные рекомендации:**

1. **Никогда не передавайте JSON-ключ** третьим лицам
2. **Храните ключи в секрете** — используйте менеджеры паролей
3. **Регулярно обновляйте ключи** — перевыпускайте раз в 3-6 месяцев
4. **Используйте минимальные права** — не давайте роль `admin` без необходимости
5. **Мониторьте использование** — проверяйте логи в консоли Яндекс Облака

## API Endpoints

### Проверка настроек

```bash
GET /api/yandex-cloud/settings
```

### Обновление настроек

```bash
PUT /api/yandex-cloud/settings
Content-Type: application/json

{
  "service_account_key": "{...}",
  "folder_id": "b1g...",
  "bucket_name": "my-bucket",
  "access_key_id": "YC...",
  "secret_access_key": "..."
}
```

### Получение IAM-токена

```bash
POST /api/yandex-cloud/iam-token
```

Ответ:
```json
{
  "iam_token": "t1.9e...",
  "expires_at": "2024-01-15T12:00:00Z"
}
```
