# Проверки перед отправкой ветки

- Docker: `python -m unittest discover -s /app -p 'test_*.py' -v` — 17/17 успешно.
- Docker: `node --test tests/recognition.test.mjs` — 4/4 успешно.
- Docker: `npm run typecheck` — успешно.
- Docker: `npm run build` — успешно; предупреждение о JS-чанке >500 kB.
- `git diff --cached --check` — успешно.
- SHA-256 зафиксированных алгоритмов совпадает с содержимым Git index.
- В отчётных файлах нет MP3/PCM и шаблонов ключей Yandex/S3.

Backend-тесты pydub выдают ResourceWarning об открытых WAV-дескрипторах; тесты проходят. Изменение замороженной подготовки аудио после просмотра тестов не выполнялось.

Семантическая проверка **не пройдена для автоматического заказа**: потеря/неверное присоединение комментария. Поэтому новая стратегия не включена в рабочий разбор и слияние в main отложено, несмотря на успешные программные тесты.
