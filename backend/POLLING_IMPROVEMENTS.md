# Улучшенный Polling для Асинхронного Распознавания

## Проблема

При асинхронном распознавании больших файлов возникала ошибка:
```
Результат не найден в ответе операции
```

Это происходило когда:
1. Операция завершена (`done=True`)
2. Но поле `response` отсутствует в ответе
3. Или `chunks` пустой

## Решение

Улучшен механизм polling с детальным логированием и умной обработкой ошибок.

## Как работает Polling

### Частота проверки

```python
# Проверяем каждые 5 секунд
time.sleep(5)

# Максимум 120 попыток = 10 минут
max_attempts = 120
```

**Почему 5 секунд?**
- Баланс между скоростью получения результата и нагрузкой на API
- SpeechKit рекомендует интервал 5-10 секунд
- 120 попыток × 5 секунд = 600 секунд = 10 минут максимум

### Логирование

Каждая попытка логируется:

```
🔄 [ASYNC] Ожидание результата...
   Интервал проверки: каждые 5 секунд
   Максимум попыток: 120 (10 минут)
   Попытка 1/120: done=False
   Попытка 2/120: done=False
   Попытка 3/120: done=True
✅ [ASYNC] Операция завершена!
   Ключи в ответе: ['id', 'done', 'response', 'createdAt', 'modifiedAt']
✅ [ASYNC] Результат получен!
   Ключи в response: ['chunks']
   Найдено chunks: 15
   Chunk 0: Привет, как дела...
   Chunk 1: Всё хорошо, спасибо...
   Chunk 2: Отлично, давай встретимся...
✅ [ASYNC] Распознавание завершено!
   Итоговый текст: 1523 символов
```

## Обработка ошибок

### Случай 1: done=True но response отсутствует

**Что происходит:**
```python
if done:
    if 'response' in operation:
        # Всё хорошо
    else:
        # done=True но response нет
        print(f"⚠️  [ASYNC] done=True но response отсутствует")
        
        # Логируем полный ответ для отладки
        print(f"   Полный ответ операции:")
        print(f"   {json.dumps(operation, indent=2)}")
        
        # Проверяем метаданные
        metadata = operation.get('metadata', {})
        if metadata:
            print(f"   Метаданные: {json.dumps(metadata, indent=2)}")
        
        # Ждём ещё 10 секунд
        if attempt < max_attempts - 5:
            print(f"   Ждём ещё 10 секунд...")
            time.sleep(10)
            continue
        else:
            raise Exception("Результат не найден...")
```

**Почему это происходит:**
- API вернул `done=True` но результат ещё обрабатывается
- Временная задержка между завершением операции и доступностью результата
- Редкий баг API

**Решение:**
- Ждём ещё 10 секунд
- Логируем полный ответ для отладки
- Проверяем метаданные

### Случай 2: chunks пустой

**Что происходит:**
```python
chunks = result.get('chunks', [])
print(f"   Найдено chunks: {len(chunks)}")

if len(chunks) == 0:
    print(f"⚠️  [ASYNC] Chunks пустой - возможно в аудио нет речи")
    print(f"   Полный response: {json.dumps(result, indent=2)}")
    return {
        'result': '',
        'chunks': [],
        'operation_id': operation_id
    }
```

**Почему это происходит:**
- В аудио файле нет речи (тишина, музыка, шум)
- Речь не распознаётся (слишком тихая, плохое качество)
- Неправильный язык

**Решение:**
- Возвращаем пустой результат
- Логируем предупреждение
- Не выбрасываем ошибку

### Случай 3: chunk без alternatives

**Что происходит:**
```python
for idx, chunk in enumerate(chunks):
    alternatives = chunk.get('alternatives', [])
    if alternatives:
        text = alternatives[0].get('text', '')
        full_text += text + ' '
    else:
        print(f"   ⚠️  Chunk {idx}: нет alternatives")
```

**Почему это происходит:**
- API вернул chunk но не смог распознать речь в нём
- Частичная ошибка распознавания

**Решение:**
- Пропускаем проблемный chunk
- Продолжаем обработку остальных
- Логируем предупреждение

## Типичные проблемы

### Проблема 1: "Результат не найден в ответе операции"

**Симптомы:**
```
✅ [ASYNC] Операция завершена!
   Ключи в ответе: ['id', 'done', 'metadata']
⚠️  [ASYNC] done=True но response отсутствует
   Полный ответ операции:
   {
     "id": "e03sup6d5h1q********",
     "done": true,
     "metadata": {...}
   }
```

**Причины:**
1. API вернул `done=True` но результат ещё не готов
2. Произошла ошибка но она не в поле `error`
3. Баг API

**Решение:**
- Ждём ещё 10 секунд (автоматически)
- Проверяем метаданные
- Если не помогло - увеличиваем `max_attempts`

### Проблема 2: "Chunks пустой"

**Симптомы:**
```
✅ [ASYNC] Результат получен!
   Ключи в response: ['chunks']
   Найдено chunks: 0
⚠️  [ASYNC] Chunks пустой - возможно в аудио нет речи
```

**Причины:**
1. В аудио нет речи (тишина, музыка)
2. Речь слишком тихая
3. Неправильный язык

**Решение:**
- Проверяем аудио файл
- Убеждаемся что есть речь
- Проверяем параметр `language`

### Проблема 3: Превышено время ожидания

**Симптомы:**
```
   Попытка 118/120: done=False
   Попытка 119/120: done=False
   Попытка 120/120: done=False
❌ [ASYNC] Превышено время ожидания (600 секунд)
```

**Причины:**
1. Файл слишком большой (> 100 МБ)
2. Сервер SpeechKit перегружен
3. Сетевые проблемы

**Решение:**
- Увеличиваем `max_attempts` до 240 (20 минут)
- Разбиваем файл на части
- Пробуем позже

## Оптимизация

### Увеличение интервала проверки

Если файлы очень большие (> 50 МБ), можно увеличить интервал:

```python
# Вместо 5 секунд
time.sleep(10)  # 10 секунд

# И уменьшить количество попыток
max_attempts = 60  # 60 × 10 = 10 минут
```

### Уменьшение интервала проверки

Если файлы маленькие (1-10 МБ), можно уменьшить интервал:

```python
# Вместо 5 секунд
time.sleep(2)  # 2 секунды

# И увеличить количество попыток
max_attempts = 300  # 300 × 2 = 10 минут
```

### Адаптивный интервал

```python
# Адаптивный интервал в зависимости от размера файла
if file_size < 10_000_000:  # < 10 МБ
    sleep_time = 2
elif file_size < 50_000_000:  # < 50 МБ
    sleep_time = 5
else:
    sleep_time = 10

time.sleep(sleep_time)
```

## Мониторинг

### Метрики для отслеживания

1. **Время распознавания**
   - Среднее: 2-3 минуты
   - Максимум: 10 минут

2. **Количество попыток**
   - Среднее: 30-40 попыток
   - Максимум: 120 попыток

3. **Процент успешных распознаваний**
   - Цель: > 95%

4. **Процент пустых результатов**
   - Цель: < 5%
