# Анализ XLSX файлов

Этот модуль позволяет анализировать структуру XLSX файлов (Excel) для подготовки к импорту данных.

## Возможности

- Анализ структуры XLSX файлов
- Определение типов данных в колонках
- Подсчёт заполненных ячеек
- Примеры значений из каждой колонки
- Статистика для числовых данных (min, max, avg)
- Копирование результата для генерации импортера

## Использование

### Через веб-интерфейс

1. Откройте приложение в браузере
2. Перейдите на вкладку **"XLSX импорт"**
3. Нажмите **"Выбрать XLSX файл"**
4. Выберите файл номенклатуры или клиентов
5. Изучите результат анализа
6. Нажмите **"Копировать для импортера"**
7. Передайте скопированный текст для генерации кода импорта

### Через командную строку

```bash
cd backend
python analyze_xlsx.py /path/to/file.xlsx
```

Пример:
```bash
python analyze_xlsx.py ~/Downloads/nomenclature.xlsx
```

## API эндпоинт

### POST /analyze-xlsx

Анализирует XLSX файл и возвращает структуру данных.

**Запрос:**
```bash
curl -X POST http://localhost:5000/analyze-xlsx \
  -F "file=@nomenclature.xlsx"
```

**Ответ:**

## Зависимости

```bash
pip install openpyxl
```

## Следующие шаги

После анализа файла:

1. Скопируйте результат анализа
2. Передайте его для генерации импортера
3. Импортер будет:
   - Читать XLSX файлы
   - Валидировать данные
   - Загружать в базу данных
   - Обрабатывать ошибки

## Примеры использования

### Анализ файла номенклатуры

```bash
python analyze_xlsx.py nomenclature.xlsx
```

Ожидаемая структура:
- Артикул
- Название
- Цена
- Категория
- Описание

### Анализ файла клиентов

```bash
python analyze_xlsx.py clients.xlsx
```

Ожидаемая структура:
- Имя
- Телефон
- Email
- Адрес
- Дата регистрации
