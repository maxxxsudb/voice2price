# Система заказов через голосовое управление

## Концепция

Менеджер находится на торговой точке и диктует заказ:
- **Клиент** (название, адрес или сокращение)
- **Номенклатура** (название товара или сокращение)
- **Количество** (число + единица измерения)

Система:
1. Использует **словарь сотрудника** для улучшения распознавания
2. Передает словарь в **Яндекс SpeechKit** вместе с аудио
3. **Парсит распознанный текст** и извлекает заказ

## Архитектура

```
┌─────────────────┐
│   Менеджер      │
│   (голос)       │

         │ "Ромашка, молоко домик 3 упаковки"
         ▼
┌─────────────────┐
│  Микрофон       │
│  (аудио)        │
└────────┬────────┘
         │
         ▼
┌─────────────────────────────────────────┐
│  Бэкенд (Flask)                         │
│                                         │
│  1. Загружает словарь сотрудника        │
│     ├── Клиенты: "Ромашка", "ромашка"   │
│     └── Номенклатура: "молоко домик"    │
│                                         │
│  2. Отправляет в SpeechKit:             │
│     ├── Аудио                           │
│     └── Словарь (для улучшения)         │
│                                         │
│  3. Получает текст:                     │
│     "Ромашка, молоко домик 3 упаковки"  │
│                                         │
│  4. Парсит заказ:                       │
│     ├── Клиент: ООО Ромашка             │

└────────┬────────────────────────────────┘
         │
         ▼
┌─────────────────┐
│  Заказ создан   │
└─────────────────┘
```

## Быстрый старт

### 1. Импорт данных сотрудника

```bash
cd backend

# Импортируем номенклатуру
python import_nomenclature_v2.py ivanov ЦыганковНоменклатура.xlsx

# Импортируем клиентов
python import_clients_v2.py ivanov Клиенты.xlsx
```

При импорте автоматически создается словарь со всеми названиями.

### 2. Добавление вариантов произношения

Менеджеры часто используют сокращения. Добавляем их в словарь:

```bash
# Добавляем сокращения для номенклатуры
python manage_voice_dict.py ivanov add "Молоко Домик в деревне 3.2%" "молоко домик" nomenclature
python manage_voice_dict.py ivanov add "Молоко Домик в деревне 3.2%" "домик в деревне" nomenclature
python manage_voice_dict.py ivanov add "Молоко Домик в деревне 3.2%" "эм дэ ноль один" nomenclature

# Добавляем сокращения для клиентов
python manage_voice_dict.py ivanov add "ООО Ромашка" "ромашка" client
python manage_voice_dict.py ivanov add "ИП Иванов И.И." "иванов" client
```

### 3. Просмотр словаря

```bash
# Показать весь словарь
python manage_voice_dict.py ivanov list

# Экспортировать в формате SpeechKit
python manage_voice_dict.py ivanov speechkit
```

### 4. Тестирование парсинга

```bash
# Парсим текст заказа
python manage_voice_dict.py ivanov parse "Ромашка, молоко домик 3 упаковки"
```

## Структура словаря

### Автоматическое создание

При импорте данных автоматически создаются записи в словаре:

**Для номенклатуры:**
- Оригинальное название
- Артикул (как вариант)
- Код (как вариант)

**Для клиентов:**
- Оригинальное название
- Код (как вариант)
- Публичное название (как вариант)

### Ручное добавление вариантов

Добавляйте сокращения и альтернативные названия:

```bash
# Формат: python manage_voice_dict.py <employee_id> add "<оригинал>" "<вариант>" <категория>

# Сокращения номенклатуры
python manage_voice_dict.py ivanov add "Хлеб Бородинский" "бородинский" nomenclature
python manage_voice_dict.py ivanov add "Хлеб Бородинский" "черный хлеб" nomenclature
python manage_voice_dict.py ivanov add "Хлеб Бородинский" "бородинка" nomenclature

# Сокращения клиентов
python manage_voice_dict.py ivanov add "Магазин Продукты" "продукты" client
python manage_voice_dict.py ivanov add "ООО Восток" "восток" client
```

### Формат SpeechKit

Словарь экспортируется в формате:
```
оригинал|вариант1,вариант2,вариант3
```

Пример:
```
Молоко Домик в деревне 3.2%|MD-001,12345,молоко домик,домик в деревне
Хлеб Бородинский|HB-002,бородинский,черный хлеб,бородинка
ООО Ромашка|CL-001,ромашка
```

## API Endpoints

### Распознавание с парсингом заказа

```bash
POST /recognize
```

Параметры:
- `file` - аудиофайл
- `api_key` - ключ SpeechKit
- `employee_id` - ID сотрудника (для использования словаря)

Ответ:
```json
{
  "text": "распознанный текст",
  "parsed_order": {
    "clients": [...],
    "nomenclatures": [...],
    "quantities": [...],
    "parsed_order": {
      "client_id": "...",
      "client_name": "...",
      "items": [...]
    }
  }
}
```

### Получение словаря

```bash
GET /employees/<employee_id>/dictionary
```

Ответ:
```json
{
  "employee_id": "ivanov",
  "dictionary": {
    "entries": [
      {
        "original": "Молоко Домик в деревне 3.2%",
        "variants": ["молоко домик", "домик в деревне"],
        "category": "nomenclature",
        "item_id": "n001"
      }
    ],
    "total_entries": 315,
    "total_terms": 450
  },
  "speechkit_format": "Молоко Домик в деревне 3.2%|молоко домик,домик в деревне"
}
```

## Преимущества

1. **Персонализация** - каждый сотрудник имеет свой словарь
2. **Точность** - SpeechKit использует словарь для лучшего распознавания
3. **Гибкость** - можно добавлять любые сокращения и альтернативы
4. **Автоматизация** - автоматический парсинг заказа из текста
5. **Масштабируемость** - легко добавлять новых сотрудников
