# Управление сотрудниками через UI

## Что добавлено

✅ **Веб-интерфейс для управления сотрудниками**
- Список всех сотрудников с количеством номенклатуры и клиентов
- Создание/удаление сотрудников
- Детальная информация о сотруднике
- Импорт номенклатуры и клиентов через UI
- Управление словарем распознавания

## Как использовать

### 1. Откройте вкладку "Сотрудники"

Первая вкладка в навигации — "Сотрудники".

### 2. Создайте сотрудника

1. Нажмите кнопку **"Добавить"**
2. Заполните форму:
   - **ID** (обязательно) — уникальный идентификатор (например: `ivanov`)
   - **Имя** (обязательно) — полное имя сотрудника
   - Email, телефон, должность (опционально)
3. Нажмите **"Создать"**

### 3. Выберите сотрудника

Кликните на карточку сотрудника в списке слева. Справа появится детальная информация.

### 4. Импортируйте данные

Перейдите на вкладку **"Импорт"** внутри карточки сотрудника:

#### Импорт номенклатуры
1. Нажмите **"Выбрать XLSX файл"** в секции "Импорт номенклатуры"
2. Выберите файл с номенклатурой
3. Дождитесь завершения импорта
4. Результат покажет количество обработанных строк

#### Импорт клиентов
1. Нажмите **"Выбрать XLSX файл"** в секции "Импорт клиентов"
2. Выберите файл с клиентами
3. Дождитесь завершения импорта

### 5. Просмотр данных

#### Номенклатура
Вкладка **"Номенклатура"** показывает список всех товаров сотрудника:
- Название
- Артикул
- Код
- Вес

#### Клиенты
Вкладка **"Клиенты"** показывает список всех клиентов:
- Название
- Код
- Регион
- Менеджер

#### Словарь
Вкладка **"Словарь"** показывает все варианты произношения:
- Оригинальное название
- Категория (клиент/номенклатура)
- Варианты произношения

### 6. Добавление голосовых вариантов

1. Перейдите на вкладку **"Словарь"**
2. Нажмите **"Добавить вариант"**
3. Заполните форму:
   - **Оригинальное название** — точное название из номенклатуры/клиентов
   - **Вариант произношения** — как менеджер может это назвать
   - **Категория** — клиент или номенклатура
4. Нажмите **"Сохранить"**

Примеры:
- Оригинал: "Молоко Домик в деревне 3.2%"
- Вариант: "молоко домик"
- Категория: "Номенклатура"

## API Endpoints

### Сотрудники

```bash
# Список сотрудников
GET /employees

# Создать сотрудника
POST /employees
{
  "id": "ivanov",
  "name": "Иванов Иван Иванович",
  "email": "ivanov@example.com",
  "phone": "+79991234567",
  "position": "Менеджер"
}

# Информация о сотруднике
GET /employees/<employee_id>

# Обновить сотрудника
PUT /employees/<employee_id>
{
  "name": "Новое имя",
  "position": "Новая должность"
}

# Удалить сотрудника
DELETE /employees/<employee_id>
```

### Номенклатура

```bash
# Список номенклатуры сотрудника
GET /employees/<employee_id>/nomenclature

# Импорт номенклатуры из XLSX
POST /employees/<employee_id>/nomenclature/import
Content-Type: multipart/form-data
file: <xlsx_file>
```

### Клиенты

```bash
# Список клиентов сотрудника
GET /employees/<employee_id>/clients

# Импорт клиентов из XLSX
POST /employees/<employee_id>/clients/import
Content-Type: multipart/form-data
file: <xlsx_file>
```

### Словарь

```bash
# Получить словарь сотрудника
GET /employees/<employee_id>/dictionary

# Добавить вариант произношения
POST /employees/<employee_id>/dictionary/add
{
  "original": "Молоко Домик в деревне 3.2%",
  "variant": "молоко домик",
  "category": "nomenclature"
}
```

### Заказы

```bash
# Список заказов сотрудника
GET /employees/<employee_id>/orders
```

## Примеры использования

### Сценарий 1: Новый менеджер

1. Создайте сотрудника с ID `manager1`
2. Импортируйте его номенклатуру из XLSX
3. Импортируйте его клиентов из XLSX
4. Добавьте голосовые варианты для часто используемых сокращений
5. Используйте распознавание речи с `employee_id=manager1`

### Сценарий 2: Добавление сокращений

Менеджер часто говорит "ромашка" вместо "ООО Ромашка":

1. Откройте вкладку "Сотрудники"
2. Выберите нужного менеджера
3. Перейдите на вкладку "Словарь"
4. Нажмите "Добавить вариант"
5. Заполните:
   - Оригинал: "ООО Ромашка"
   - Вариант: "ромашка"
   - Категория: "Клиент"
6. Сохраните

Теперь при распознавании речи "ромашка" будет автоматически сопоставлена с "ООО Ромашка".

### Сценарий 3: Массовое добавление вариантов

Если нужно добавить много вариантов:

1. Используйте CLI команду:
```bash
docker compose exec backend bash
python manage_voice_dict_db.py ivanov add "Молоко Домик" "молоко домик" nomenclature
python manage_voice_dict_db.py ivanov add "Молоко Домик" "домик" nomenclature
python manage_voice_dict_db.py ivanov add "ООО Ромашка" "ромашка" client
```

2. Обновите страницу в браузере — варианты появятся в словаре

## Решение проблем

### Ошибка "Бэкенд не запущен"

Убедитесь что бэкенд запущен:
```bash
docker compose ps
```

Если backend не в списке:
```bash
docker compose up -d backend
```

### Ошибка при импорте

Проверьте логи бэкенда:
```bash
docker compose logs -f backend
```

Частые проблемы:
- Файл не в формате XLSX
- Неправильная структура файла
- Сотрудник не найден

### Словарь не обновляется

После добавления вариантов через CLI, обновите страницу в браузере (F5).
