# Редактирование импортированной номенклатуры

## Проблема

Ранее после импорта номенклатуры из XLSX не было возможности просмотреть и редактировать импортированные данные, включая варианты произношения.

## Решение

Добавлена возможность:
1. Просматривать все импортированные элементы номенклатуры, клиентов и единиц измерения
2. Разворачивать карточку элемента для просмотра деталей
3. Добавлять новые варианты произношения
4. Удалять существующие варианты произношения
5. Видеть все варианты сразу (первые 3 в свернутом виде, все в развернутом)

## Как использовать

### Просмотр номенклатуры

1. Перейдите на вкладку **"Сотрудники"**
2. Выберите сотрудника
3. Перейдите на вкладку **"Номенклатура"**
4. Вы увидите список всех импортированных товаров

### Редактирование элемента

1. **Кликните на карточку** товара чтобы развернуть её
2. В развернутом виде вы увидите:
   - Полную информацию о товаре
   - Все варианты произношения
   - Кнопки удаления для каждого варианта
   - Форму добавления нового варианта

### Добавление варианта

1. Разверните карточку товара
2. Нажмите кнопку **"+"** справа
3. Введите вариант произношения
4. Нажмите **"✓"** или Enter

### Удаление варианта

1. Разверните карточку товара
2. Найдите вариант в списке
3. Нажмите кнопку **🗑️** (корзина) справа от варианта
4. Подтвердите удаление

## Пример использования

### Сценарий: Исправление дефекта распознавания

**Проблема:** Менеджер говорит "молоко домик", но система не распознает это как "Молоко Домик в деревне 3.2%"

**Решение:**

1. Перейдите на вкладку **"Сотрудники"** → выберите сотрудника
2. Перейдите на вкладку **"Номенклатура"**
3. Найдите товар "Молоко Домик в деревне 3.2%"
4. Кликните на карточку чтобы развернуть
5. Нажмите **"+"** чтобы добавить вариант
6. Введите: `молоко домик`
7. Нажмите **"✓"**

Теперь при распознавании речи "молоко домик" будет автоматически сопоставлено с "Молоко Домик в деревне 3.2%"

### Сценарий: Удаление неправильного варианта

**Проблема:** Был добавлен неправильный вариант "домик" который вызывает ложные срабатывания

**Решение:**

1. Разверните карточку товара
2. Найдите вариант "домик" в списке
3. Нажмите **🗑️** справа от варианта
4. Подтвердите удаление

## API изменения

### Новые endpoints

```bash
# Удалить вариант произношения номенклатуры/клиента
DELETE /employees/<employee_id>/dictionary/variant/<variant_id>

# Удалить вариант произношения единицы измерения
DELETE /employees/<employee_id>/units/<unit_id>/variants/<variant_id>
```

### Обновленные responses

Теперь API возвращает варианты произношения вместе с элементами:

```json
{
  "id": "n12345678",
  "name": "Молоко Домик в деревне 3.2%",
  "article": "MD-001",
  "variants": [
    {
      "id": 1,
      "variant": "молоко домик",
      "confidence": 1.0
    },
    {
      "id": 2,
      "variant": "домик в деревне",
      "confidence": 1.0
    }
  ]
}
```

## Компоненты

### NomenclatureItem

- Добавлено состояние `expanded` для развертывания
- Добавлена функция `handleDeleteVariant` для удаления вариантов
- UI показывает первые 3 варианта в свернутом виде
- В развернутом виде показывает все варианты с кнопками удаления

### ClientItem

- Аналогичные изменения как в NomenclatureItem
- Цветовая схема: зеленая (вместо фиолетовой)

### UnitItem

- Аналогичные изменения
- Цветовая схема: cyan (вместо фиолетовой)
