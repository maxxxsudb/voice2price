# Управление вариантами произношения

## Обзор

Теперь вы можете добавлять варианты произношения прямо в списках номенклатуры, клиентов и единиц измерения. Это позволяет менеджеру использовать сокращения и альтернативные названия при диктовке заказов.

## Возможности

### 1. Номенклатура

В списке номенклатуры каждый элемент имеет кнопку "+" для добавления вариантов произношения.

**Пример:**
- Оригинал: "Молоко Домик в деревне 3.2%"
- Варианты: "молоко домик", "домик в деревне", "эм дэ ноль один"

### 2. Клиенты

В списке клиентов каждый элемент имеет кнопку "+" для добавления вариантов произношения.

**Пример:**
- Оригинал: "ООО Ромашка"
- Варианты: "ромашка", "ооо ромашка"

### 3. Единицы измерения

Новая вкладка "Ед. измерения" позволяет управлять единицами измерения с вариантами произношения.

**Пример:**
- Оригинал: "килограмм"
- Варианты: "кг", "кило", "полкило", "300 грамм"

## Как использовать

### Добавление варианта произношения

1. Перейдите на вкладку **"Сотрудники"**
2. Выберите сотрудника
3. Перейдите на нужную вкладку:
   - **Номенклатура** - для товаров
   - **Клиенты** - для клиентов
   - **Ед. измерения** - для единиц измерения
4. Найдите нужный элемент в списке
5. Нажмите кнопку **"+"** справа от элемента
6. Введите вариант произношения
7. Нажмите **"✓"** или Enter

## Единицы измерения

### Зачем нужны?

Менеджеры часто диктуют вес или количество в разных форматах:
- "2 штуки"
- "1.5 кг"
- "полкило"
- "300 грамм"

Единицы измерения позволяют системе понимать эти варианты.

### Как добавить единицу измерения

Пока единицы измерения добавляются через API:

```bash
curl -X POST http://localhost:5000/employees/ivanov/units \
  -H "Content-Type: application/json" \
  -d '{
    "name": "килограмм",
    "abbreviation": "кг",
    "category": "вес"
  }'
```

Затем добавьте варианты:

```bash
curl -X POST http://localhost:5000/employees/ivanov/units/u12345678/variants \
  -H "Content-Type: application/json" \
  -d '{
    "variant": "кг"
  }'
```

### Категории единиц измерения

- **вес** - кг, г, тонна
- **количество** - шт, штука, единица
- **объем** - л, мл, литр
- **длина** - м, см, метр

## Указание количества в заказах

При диктовке заказа менеджер указывает количество:

**Примеры:**
- "Ромашка, молоко домик 2 штуки"
- "Восток, хлеб бородинский 1.5 кг"
- "Продукты, масло сливочное полкило"

Система автоматически:
1. Распознает клиента
2. Распознает номенклатуру
3. Извлекает количество и единицу измерения
4. Создает заказ

## API Endpoints

### Номенклатура с вариантами

```bash
GET /employees/<employee_id>/nomenclature
```

Возвращает номенклатуру с массивом `variants` для каждого элемента.

### Клиенты с вариантами

```bash
GET /employees/<employee_id>/clients
```

Возвращает клиентов с массивом `variants` для каждого элемента.

### Единицы измерения

```bash
# Получить список
GET /employees/<employee_id>/units

# Создать единицу
POST /employees/<employee_id>/units
{
  "name": "килограмм",
  "abbreviation": "кг",
  "category": "вес"
}

# Добавить вариант
POST /employees/<employee_id>/units/<unit_id>/variants
{
  "variant": "кг"
}
```

## Преимущества

✅ **Inline добавление** - не нужно переходить на другую вкладку  
✅ **Визуальная обратная связь** - варианты отображаются прямо в списке  
✅ **Быстрое редактирование** - один клик для добавления варианта  
✅ **Гибкость** - можно добавить любое количество вариантов  
✅ **Интуитивность** - понятно как использовать
