# Анализ XLSX файлов для импорта

## Зачем это нужно

Перед написанием импортера нужно понять структуру ваших Excel файлов:
- Какие колонки есть
- Какие типы данных (текст, числа, даты)
- Примеры значений
- Есть ли заголовки

## Установка

```bash
cd backend
pip install openpyxl
```

## Использование

### 1. Проанализируйте файл номенклатуры

```bash
python analyze_xlsx.py nomenclature.xlsx
```

### 2. Проанализируйте файл клиентов

```bash
python analyze_xlsx.py clients.xlsx
```

### 3. Скопируйте вывод

Скопируйте весь вывод скрипта и передайте его для генерации импортера.

## Что покажет скрипт

- **Структура файла**: количество листов, строк, колонок
- **Заголовки колонок**: названия из первой строки
- **Типы данных**: текст, числа, даты
- **Примеры значений**: первые 5 значений из каждой колонки
- **Статистика**: для числовых колонок (min, max, avg)

## Следующий шаг

После анализа передайте вывод скрипта для генерации импортера:

```
Вот структура моих файлов:
[вставьте вывод analyze_xlsx.py]

Напиши импортер для номенклатуры и клиентов.
```

Импортер будет:
- Читать XLSX файлы
- Валидировать данные
- Загружать в базу данных
- Обрабатывать ошибки
