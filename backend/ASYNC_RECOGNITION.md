# Асинхронное распознавание больших файлов

## Проблема

Синхронный API Яндекс SpeechKit имеет ограничение на размер файла **1 МБ** (после конвертации в PCM). При попытке отправить больший файл возвращается ошибка:

```
SpeechKit API error 400: {"error_code":"BAD_REQUEST","error_message":"audio should be less than 1 mb"}
```

## Решение

Для больших файлов используется **асинхронный API v3** (`recognizeFileAsync`), который:
- Поддерживает файлы до **1 ГБ** (через Object Storage) или напрямую в запросе
- Использует модели `deferred-general` для отложенной обработки
- Работает с MP3, WAV, OGG напрямую без конвертации в PCM
- Возвращает результат через polling (до 10 минут)

## Как это работает

### Автоматический выбор API

Бэкенд автоматически выбирает API в зависимости от размера файла:

```python
# Если файл > 1 МБ - используем асинхронный API
use_async = file_size > 1_000_000  # > 1 МБ
```

### Синхронный API (файлы < 1 МБ)

- URL: `https://stt.api.cloud.yandex.net/speech/v1/stt:recognize`
- Модель: `general`, `general:rc`, и т.д.
- Формат: PCM 16kHz mono 16bit
- Время ответа: несколько секунд
- Лимит: 1 МБ

### Асинхронный API (файлы > 1 МБ)

- URL: `https://stt.api.cloud.yandex.net/stt/v3/recognizeFileAsync`
- Модель: `deferred-general`, `deferred-general:rc`
- Формат: MP3, WAV, OGG_OPUS напрямую
- Время ответа: до 10 минут (polling каждые 5 секунд)
- Лимит: до 1 ГБ

## Использование

### Через веб-интерфейс

1. Загрузите аудиофайл (любого размера)
2. Нажмите "Распознать речь"
3. Если файл > 1 МБ - увидите сообщение:
   ```
   ⚡ Файлы > 1 МБ будут обработаны через асинхронный API (может занять до 10 минут)
   ```
4. Дождитесь завершения (кнопка показывает "Обработка... (большие файлы могут обрабатываться до 10 минут)")

### Через API

```bash
curl -X POST http://localhost:5000/recognize \
  -F "file=@large_audio.mp3" \
  -F "api_key=YOUR_API_KEY" \
  -F "language=ru-RU" \
  -F "model=general"
```

Бэкенд автоматически выберет нужный API.

## Модели для асинхронного распознавания

| Модель | Описание | Использование |
|--------|----------|---------------|
| `deferred-general` | Основная модель для больших файлов | По умолчанию для файлов > 1 МБ |
| `deferred-general:rc` | Модель с улучшенным распознаванием | Для важного контента |
| `deferred-general:deprecated` | Устаревшая модель | Не рекомендуется |

Автоматический выбор:
```python
# Если пользователь выбрал "general" - используем "deferred-general"
async_model = 'deferred-general' if model == 'general' else f'deferred-{model}'
```

## Форматы аудио

### Поддерживаемые форматы

- **MP3** - отправляется напрямую без конвертации
- **WAV** - отправляется напрямую без конвертации
- **OGG_OPUS** - отправляется напрямую без конвертации
- **Другие форматы** - конвертируются в PCM 16kHz mono 16bit

### Определение формата

```python
file_ext = Path(file.filename).suffix.lower()
if file_ext == '.mp3':
    audio_format = 'MP3'
elif file_ext == '.wav':
    audio_format = 'WAV'
elif file_ext in ['.ogg', '.opus']:
    audio_format = 'OGG_OPUS'
else:
    # Конвертируем в PCM
    audio_format = 'LINEAR16_PCM'
```

## Ограничения

### Синхронный API
- Максимальный размер: 1 МБ (PCM)
- Максимальная длительность: ~1 минута
- Время ответа: несколько секунд

### Асинхронный API
- Максимальный размер: 1 ГБ (через Object Storage)
- Максимальная длительность: до 4 часов
- Время ответа: до 10 минут
- Результаты хранятся 3 дня

## Polling механизм

```python
max_attempts = 120  # Максимум 120 попыток
attempt = 0

while attempt < max_attempts:
    time.sleep(5)  # Ждём 5 секунд
    attempt += 1
    
    # Проверяем статус операции
    operation = check_operation_status(operation_id)
    
    if operation['done']:
        # Получаем результат
        return operation['response']
```

**Время ожидания:**
- 120 попыток × 5 секунд = 600 секунд = 10 минут
- Обычно результат готов через 1-3 минуты

## Обработка ошибок

### Ошибка при создании операции

```
❌ [ASYNC] Ошибка API: 400
   Ответ: {"error_code":"BAD_REQUEST","error_message":"..."}
```

**Решение:** Проверьте API ключ, формат файла, параметры запроса

### Ошибка при распознавании

```
❌ [ASYNC] Ошибка распознавания: {"message":"Audio format not supported"}
```

**Решение:** Проверьте формат аудиофайла, конвертируйте в поддерживаемый формат

### Превышено время ожидания

```
❌ [ASYNC] Превышено время ожидания (600 секунд)
```

**Решение:** 
- Файл слишком большой или сложный
- Попробуйте разбить на части
- Увеличьте `max_attempts` в коде

## Производительность

### Время распознавания

| Размер файла | Длительность аудио | Время распознавания |
|--------------|-------------------|---------------------|
| 1 МБ | ~1 мин | 10-30 секунд |
| 10 МБ | ~10 мин | 1-2 минуты |
| 50 МБ | ~50 мин | 5-10 минут |
| 100 МБ | ~100 мин | 10-15 минут |

### Оптимизация

1. **Используйте MP3** - не нужна конвертация в PCM
2. **Моно аудио** - меньше данных для обработки
3. **16 kHz** - достаточно для распознавания речи
4. **Разбивайте очень длинные файлы** - на части по 30-60 минут

## Интеграция с Object Storage

Для файлов > 100 МБ рекомендуется использовать Yandex Object Storage:

1. Загрузите файл в бакет
2. Получите URI: `s3://bucket-name/audio.mp3`
3. Отправьте URI вместо `content` в запросе

```python
request_body = {
    "uri": "s3://bucket-name/audio.mp3",
    "recognitionModel": {
        "model": "deferred-general",
        ...
    }
}
```
