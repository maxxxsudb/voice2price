# Сохранение настроек API и улучшение UI

## Проблема

1. **Настройки API не сохранялись** - при перезагрузке страницы API ключ и другие настройки терялись
2. **Непонятно почему кнопка отправки неактивна** - пользователь загружал файл, но не видел кнопку отправки или не понимал почему она не работает

## Решение

### 1. Сохранение настроек API в localStorage

**Что сделано:**
- Настройки API теперь автоматически сохраняются в `localStorage` браузера
- При загрузке страницы настройки восстанавливаются из `localStorage`
- Добавлен индикатор "Сохранено" при изменении настроек
- Добавлена подсказка об автосохранении

**Код:**
```typescript
// Инициализация с загрузкой из localStorage
const [apiConfig, setApiConfig] = useState<ApiConfig>(() => {
  const saved = localStorage.getItem('apiConfig');
  return saved ? JSON.parse(saved) : {
    apiKey: '',
    folderId: '',
    language: 'ru-RU',
    model: 'general',
  };
});

// Сохранение при изменении
const updateApiConfig = (config: ApiConfig) => {
  setApiConfig(config);
  localStorage.setItem('apiConfig', JSON.stringify(config));
  console.log('✅ [FRONTEND] Настройки API сохранены в localStorage');
};
```

### 2. Улучшение UI для кнопки отправки

**Что сделано:**
- Добавлены понятные подсказки почему кнопка неактивна
- Добавлена кнопка быстрого перехода к настройкам API
- Добавлена проверка доступности бэкенда при загрузке страницы
- Добавлены визуальные индикаторы проблем

**Подсказки:**
- Если API ключ не указан:
  ```
  ⚠️ API ключ не указан. Перейдите на вкладку "Настройки API" и укажите ключ Яндекс SpeechKit.
  [Открыть настройки →]
  ```

- Если бэкенд недоступен:
  ```
  🖥️ Бэкенд недоступен. Убедитесь что бэкенд запущен на http://localhost:5000
  ```

### 3. Автоматическая проверка бэкенда

**Что сделано:**
- При загрузке страницы автоматически проверяется доступность бэкенда
- Результат проверки отображается в шапке (зеленая/красная точка)
- Пользователь сразу видит статус бэкенда

**Код:**
```typescript
// Автоматическая проверка бэкенда при загрузке
useEffect(() => {
  checkBackend();
}, []);
```

## Как использовать

### Первый запуск

1. Откройте приложение
2. Перейдите на вкладку **"Настройки API"**
3. Укажите API ключ Яндекс SpeechKit
4. Настройки автоматически сохранятся (появится индикатор "Сохранено")
5. Перейдите на вкладку **"Загрузка файлов"**
6. Загрузите аудиофайл
7. Нажмите кнопку **"Распознать речь"**

### Последующие запуски

1. Откройте приложение
2. Настройки API уже загружены из localStorage
3. Сразу загружайте файлы и распознавайте

### Если кнопка отправки неактивна

Проверьте подсказки под кнопкой:

**"API ключ не указан"**
- Нажмите "Открыть настройки →"
- Укажите API ключ
- Вернитесь на вкладку "Загрузка файлов"

**"Бэкенд недоступен"**
- Проверьте что бэкенд запущен: `docker compose ps`
- Если не запущен: `docker compose up -d backend`
- Проверьте доступность: `curl http://localhost:5000/health`

## Проверка работы

### 1. Проверка сохранения настроек

1. Откройте вкладку "Настройки API"
2. Укажите API ключ
3. Должен появиться индикатор "✅ Сохранено"
4. Обновите страницу (F5)
5. Вернитесь на вкладку "Настройки API"
6. API ключ должен быть на месте

### 2. Проверка в консоли браузера

Откройте консоль (F12) и проверьте:

```
✅ [FRONTEND] Настройки API сохранены в localStorage
```

### 3. Проверка в DevTools

1. Откройте DevTools (F12)
2. Перейдите на вкладку "Application"
3. В разделе "Local Storage" найдите ваш сайт
4. Должен быть ключ `apiConfig` с JSON объектом:

```json
{
  "apiKey": "your-api-key",
  "folderId": "",
  "language": "ru-RU",
  "model": "general"
}
```

## Решение проблем

### Проблема: Настройки не сохраняются

**Причина:** localStorage отключен или недоступен

**Решение:**
1. Проверьте настройки браузера
2. Убедитесь что cookies и localStorage разрешены
3. Попробуйте другой браузер

### Проблема: Кнопка отправки не появляется

**Причина:** Не загружены файлы или не указан API ключ

**Решение:**
1. Проверьте что файлы загружены (должен быть список файлов)
2. Проверьте что API ключ указан (вкладка "Настройки API")
3. Проверьте подсказки под кнопкой

### Проблема: Кнопка серая (disabled)

**Причина:** Одно из условий не выполнено

**Решение:**
1. Прочитайте подсказку под кнопкой
2. Выполните рекомендации
3. Кнопка станет активной
