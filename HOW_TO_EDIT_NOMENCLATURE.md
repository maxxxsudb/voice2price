# Инструкция: Как редактировать импортированную номенклатуру

## Проблема

После импорта номенклатуры из XLSX вы не видите список и не можете редактировать варианты произношения.

## Решение

### Шаг 1: Откройте вкладку "Сотрудники"

1. В верхней навигации нажмите на вкладку **"Сотрудники"** (первая вкладка)
2. Вы увидите список сотрудников слева

### Шаг 2: Выберите сотрудника

1. В списке слева кликните на нужного сотрудника (например, "Иванов")
2. Справа откроется детальная информация о сотруднике

### Шаг 3: Перейдите на вкладку "Номенклатура"

1. В верхней части правой панели вы увидите табы:
   - **Номенклатура** ← нажмите сюда
   - Клиенты
   - Ед. измерения
   - Словарь
   - Импорт

2. Нажмите на вкладку **"Номенклатура"**

### Шаг 4: Просмотр списка номенклатуры

Вы увидите список всех импортированных товаров. Каждый товар отображается как карточка с:
- Названием товара
- Артикулом, кодом, весом
- Первыми 3 вариантами произношения (если есть)
- Кнопкой "+" справа для добавления вариантов

### Шаг 5: Разверните карточку товара

**Кликните на карточку товара** (на любую часть кроме кнопки "+")

Карточка развернется и покажет:
- Полную информацию о товаре
- **Все варианты произношения** в виде списка
- Кнопки "🗑️" (корзина) для удаления каждого варианта
- Форму добавления нового варианта

### Шаг 6: Добавьте вариант произношения

1. В развернутой карточке нажмите кнопку **"+"** справа
2. Появится поле ввода
3. Введите вариант произношения (например: "молоко домик")
4. Нажмите **"✓"** или клавишу Enter
5. Вариант добавится в список

### Шаг 7: Удалите вариант произношения

1. В развернутой карточке найдите вариант в списке
2. Нажмите кнопку **"🗑️"** (корзина) справа от варианта
3. Подтвердите удаление

### Шаг 8: Обновите список (если нужно)

Если список не обновился автоматически, нажмите кнопку **"🔄"** (обновить) в правом верхнем углу вкладки "Номенклатура"

## Проверка через консоль браузера

Если список не отображается, откройте консоль браузера (F12) и проверьте:

1. **Загрузилась ли номенклатура?**
   ```
   📦 [FRONTEND] Загрузка номенклатуры для сотрудника: ivanov
   📥 [FRONTEND] Статус ответа: 200
   ✅ [FRONTEND] Получено номенклатуры: 315
   ```

2. **Есть ли ошибки?**
   ```
   ❌ [FRONTEND] Ошибка загрузки номенклатуры: ...
   ```

## Проверка через логи бэкенда

В терминале где запущен бэкенд вы должны увидеть:

## Частые проблемы

### Проблема 1: Список пустой

**Причина:** Номенклатура не импортирована

**Решение:**
1. Перейдите на вкладку **"Импорт"**
2. Нажмите **"Выбрать XLSX файл"** в секции "Импорт номенклатуры"
3. Выберите файл и дождитесь завершения импорта
4. Вернитесь на вкладку **"Номенклатура"**

### Проблема 2: Ошибка "Employee not found"

**Причина:** Сотрудник не существует

**Решение:**
1. Убедитесь что вы выбрали сотрудника из списка
2. Если список пуст - создайте сотрудника через кнопку **"Добавить"**

### Проблема 3: Варианты не сохраняются

**Причина:** Ошибка API или бэкенда

**Решение:**
1. Проверьте логи бэкенда в терминале
2. Проверьте консоль браузера (F12)
3. Перезапустите бэкенд: `docker compose restart backend`

### Проблема 4: Клик не разворачивает карточку

**Причина:** JavaScript ошибка

**Решение:**
1. Откройте консоль браузера (F12)
2. Проверьте есть ли ошибки (красным)
3. Обновите страницу (F5)

