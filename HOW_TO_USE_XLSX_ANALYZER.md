# Как использовать анализатор XLSX

## Что сделано

Добавлен функционал анализа XLSX файлов для подготовки к импорту номенклатуры и клиентов.

## Как использовать

### 1. Запустите приложение

```bash
docker compose up
```

### 2. Откройте в браузере

```
http://localhost:3000
```

### 3. Перейдите на вкладку "XLSX импорт"

### 4. Загрузите XLSX файл

- Нажмите "Выбрать XLSX файл"
- Выберите файл номенклатуры или клиентов
- Дождитесь окончания анализа

### 5. Изучите результат

Анализатор покажет:
- Структуру файла (листы, колонки)
- Типы данных (текст, числа, даты)
- Примеры значений из каждой колонки
- Статистику для числовых данных
- Количество заполненных ячеек

### 6. Скопируйте результат

Нажмите кнопку **"Копировать для импортера"**

### 7. Передайте для генерации импортера

Передайте скопированный текст с просьбой написать импортер:

```
Вот структура моих файлов:
[вставьте скопированный текст]

Напиши импортер для номенклатуры и клиентов.
```

## Альтернатива: через командную строку

Если не хотите использовать веб-интерфейс:

```bash
# Войдите в контейнер бэкенда
docker compose exec backend bash

# Запустите анализатор
python analyze_xlsx.py /path/to/file.xlsx
```

## Что дальше

После получения структуры данных можно написать импортер, который:
- Читает XLSX файлы
- Валидирует данные
- Загружает в базу данных
- Обрабатывает ошибки
- Показывает прогресс
