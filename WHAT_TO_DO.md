# Что делать если экран пропадает

## Проблема
После загрузки XLSX файла:
- Крутится колёсико ~5 секунд
- Экран приложения пропадает

## Решение

### 1. Откройте логи бэкенда

В отдельном терминале:
```bash
docker compose logs -f backend
```

### 2. Откройте консоль браузера

1. Нажмите F12
2. Перейдите на вкладку **Console**
3. Очистите консоль (кнопка 🚫)

### 3. Попробуйте загрузить файл снова

Смотрите что появляется в логах:

**В терминале (бэкенд):**
```
======================================================================
📊 [XLSX ANALYZE] Начало анализа файла
======================================================================
✅ [XLSX ANALYZE] Получен файл: ...
```

**В консоли браузера (фронтенд):**
```
======================================================================
📊 [FRONTEND] Начало анализа XLSX файла
======================================================================
📁 [FRONTEND] Выбран файл: ...
```

### 4. Скопируйте логи

Если есть ошибка - скопируйте:
- Последние 50 строк из терминала (бэкенд)
- Скриншот консоли браузера (фронтенд)

### 5. Пришлите логи

Пришлите скопированные логи - по ним будет видно где проблема.

## Частые причины

### 1. Бэкенд не запущен
```bash
docker compose ps
# Если backend не в списке:
docker compose up backend
```

### 2. Ошибка CORS
В консоли браузера будет:
```
Access to fetch at ... blocked by CORS policy
```
Решение: перезапустить бэкенд
```bash
docker compose restart backend
```

### 3. Бэкенд упал с ошибкой
В терминале будет traceback с ошибкой.

### 4. Ошибка при рендере
В консоли браузера будет:
```
Cannot read property '...' of undefined
```
Решение: обновить страницу (F5)

## Быстрая проверка

```bash
# 1. Проверить что бэкенд работает
curl http://localhost:5000/health

# Должно вернуть:
# {"service":"audio-analyzer-backend","status":"ok","version":"1.0.0"}

# 2. Перезапустить всё
docker compose down
docker compose up --build

# 3. Открыть заново
# http://localhost:3000
```

## Если ничего не помогает

1. Полная очистка:
```bash
docker compose down -v
docker system prune -a
```

2. Пересборка:
```bash
docker compose up --build
```

3. Пришлите логи:
- `docker compose logs backend` (последние 100 строк)
- Скриншот консоли браузера (F12 → Console)
